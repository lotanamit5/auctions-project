## Results

Additive model (eps = 0)
- Replication: LP N=50 -> 0.841225 (paper 0.841); LIP(2) in [0.8281462, 0.8281472]; Figure 1.
- The LP bound decreases with N (0.8363 at N=200, ->~0.8345): 0.841 is an N=50 artefact.
- a = 2 is not optimal: a* = 2.1013, alpha* = 0.82939; alpha(a) = min(theta(a), beta(a)),
  beta in closed form (theory/01).
- Fixed-menu (swap-dictatorial) mechanisms, in fact any mixture of two one-sided rules, are at
  most 5/6-competitive, and 5/6 is attained by an explicit menu (steepest-chain construction).
  So: LIP 0.8294 < menus = 0.8333 < all SP <~ 0.835.

Complementarity model (eps > 0), theory/02-04
- First best = 1 + max(eps, |x-y|); take-all is first best for eps >= 1.
- eps-aware LIP (fixed menu of deterministic bundles) is strategy-proof; equals the draft's
  "strategic LIP". Nested LIP (lottery over whole items, comonotone): free improvement, ratio 1
  at eps >= 1.
- Upper bound on all SP mechanisms: McCormick-moment LP (P7): 0.84 (eps=0) -> 0.95 (0.5) -> 1.
- Menu bound min{(5+2eps)/6, (1+eps)/(1+2eps-eps^2)}: tight at eps = 0 and eps >= 0.24; the menu
  LP is lower by up to 0.018 at eps ~0.17 (`results/data/sd_lp_dense.csv`). Attained for
  eps >= 1/2 by the "modest dictator" (share s* = (1-eps^2)/(1+2eps-eps^2)).
- SMD ("split if strongly opposed, x >= (1+eps)/2 and y <= (1-eps)/2, else modest dictator") is
  strategy-proof with ratio 2(1+eps)^2/(3+3eps+2eps^2) (eps <= 1/2) and (1+eps)^2/(1+3eps)
  (eps >= 1/2): beats every menu for eps > (sqrt3-1)/2 = 0.366 and nested LIP from eps ~0.35
  (`experiments/smd_crossover.py`). LP-optimised fallback menus add ~0.02-0.05 for eps in
  [0.25, 0.45].
- Naive additive rule under eps > 0: not SP, gains <= eps Q(1/2)^2/2, strategic play = eps-aware LIP.
- Substitutes (eps < 0): sketch only (notebook 06).
