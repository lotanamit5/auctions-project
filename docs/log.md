- **Observation.** For eps >= 1 the first best is always "everything to one agent" and the
  random-dictator-takes-all mechanism achieves it: competitive ratio 1. So the interesting
  regime is eps in [0, 1). Random-takes-all is LIP(a) with a -> infinity.
- **Idea for the eps upper bound.** Utility is bilinear in (z1, z2), so a lottery over
  bundles only matters through (E z1, E z2, E z1 z2). The convex hull of
  {(z1, z2, z1 z2)} over the unit square is the McCormick envelope
  {m12 >= 0, m12 >= m1 + m2 - 1, m12 <= m1, m12 <= m2}. Hence an LP over moments captures all
  randomised mechanisms exactly on a discrete type grid -> valid upper bound for the
  continuous model (type restriction only relaxes constraints).
- **Idea for LP size.** Utilities are affine in the one-dimensional type x, so full
  strategy-proofness is equivalent to adjacent-type constraints plus monotonicity of
  (m1 - m2) in x. This cuts constraints from O(N^3) to O(N^2); to be validated against the
  full LP on small N before relying on it.
